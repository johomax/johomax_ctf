# Season 2 solo BR combat model

This is the behavior of the engine checkout at `/private/tmp/engine-main-v43` under `/tmp/johomax-s2-config-solo-v2.json`. Code paths below are relative to that checkout; `manifest` means the JSON file. The live shape is sixteen one-seat teams, four base HP, BR/downed mode enabled, and a `3211 x 1713` flagless pinned map (`manifest:1`). Simulation time is twenty-four ticks per second (`src/ctf/sim_types.nim:741`).

## Perception

| Surface | Exact behavior |
|---|---|
| Forward sight | The cone reaches `gunRange * 3 div 2`; the live `gunRange` is `1300`, so its nominal radius is **1950 px** (`manifest:1`; `src/ctf/sim.nim:5534-5540`). Its half-angle is **60 degrees**, hence a **120-degree** full cone (`manifest:1`; `src/ctf/sim.nim:5570-5589`). |
| Near sight | An omnidirectional **90 px** bubble is unioned with the cone and is not range-capped (`manifest:1`; `src/ctf/sim.nim:5577-5608`). |
| Quantization and walls | Visibility is evaluated on **8 px** FOV cells (`src/ctf/sim_types.nim:837`). A cell is opaque when at least half of its pixels are wall, and recursive shadowcasting stops sight behind such cells (`src/ctf/sim.nim:5457-5471`; `src/ctf/sim.nim:5542-5568`). Stone walls therefore block sight. A placed cardboard barrier explicitly does **not** block sight (`src/ctf/sim_types.nim:4080-4086`). |
| Enemy tracks | Only living, non-team seats whose center is currently visible produce an update; that update includes seat, team, position, readable aim, total current base-plus-shield HP, shield state, held weapon class, veteran marker, downed state, and the current body tick (`src/ctf/server.nim:3764-3791`). An absent update does not delete an old track: the body overwrites only seats seen this tick (`src/shell/body.nim:598-622`). Thus `fresh_tick` means “last confirmed,” not expiry (`src/shell/schemas/play_view.schema.json:212-218`). Old tracks can remain in a play view for the episode, but native combat accepts only `freshTick == tick` (`src/shell/body.nim:815-831`; `src/shell/body.nim:858-869`). |
| `aggressors` | Victim-private hit feedback, newest first, retained for ages strictly below **120 ticks**, capped at **16 rows**. A row carries `tick`, incoming `dir_brads`, and optional attacker `seat`; the seat is omitted if the attacker was outside the victim's vision at impact. It carries no weapon or position (`src/shell/body.nim:20-26`; `src/shell/body.nim:356-357`; `src/shell/schemas/play_view.schema.json:276-299`; `src/ctf/sim.nim:100-125`). Gun, spray, and player-grenade damage all record this channel (`src/ctf/sim.nim:3554-3563`; `src/ctf/sim.nim:3969-3971`; `src/ctf/sim.nim:4540-4544`). |
| `kill_feed` | Public, newest first, retained for ages strictly below **240 ticks**, capped at **32 rows**. A row contains only `tick`, killer **team**, and victim `seat`: no killer seat, location, or weapon (`src/shell/body.nim:20-26`; `src/shell/body.nim:630-646`; `src/shell/schemas/play_view.schema.json:301-324`; `src/shell/view.nim:409-414`). |

The play callback cadence is every **6 ticks**, but the retained body and its native weapon decision run every sim tick (`manifest:1`; `src/shell/default_play.nim:1-2`; `src/shell/body.nim:1334-1358`).

## Gun

### Which range wins

The solo pool documents map defaults of **331 px** on `3211 x 1713` maps (`src/ctf/br_map_pool.nim:170-185`), and the pinned `mapSpec.gunRange` is indeed `331`; however the same live manifest explicitly sets top-level `gunRange: 1300` (`manifest:1`). Config parsing reads that top-level key, resolves the explicit map spec, and copies the map's range only when the top-level key is absent (`src/ctf/sim_config.nim:1243-1261`; `src/ctf/sim_config.nim:1320-1323`; `src/ctf/sim_config.nim:1363-1380`). Every live shot and scoring-distance scale reads `sim.config.gunRange` (`src/ctf/sim.nim:3711-3714`; `src/ctf/sim.nim:3753-3758`; `src/ctf/sim.nim:3883-3892`; `src/ctf/sim.nim:2934-2935`). **The league gun range is therefore 1300 px; 331 is overridden map metadata.**

### Shot model

| Property | Live behavior |
|---|---|
| Projectile | **Hitscan at release**, not a moving projectile. All releasing shots choose targets against one post-movement snapshot, then apply damage in that tick; the tracer is cosmetic (`src/ctf/sim.nim:5179-5189`; `src/ctf/sim.nim:8271-8275`; `src/ctf/sim.nim:3869-3877`). |
| Timing | Pulling the trigger locks aim and starts a **5-tick** windup; release sets a **12-tick** cooldown, decremented once per sim tick (`manifest:1`; `src/ctf/sim.nim:4174-4183`; `src/ctf/sim.nim:3832-3853`; `src/ctf/sim.nim:8279-8285`). At **24 ticks/s**, these are about **0.208 s** and **0.500 s**; perfectly edged raw input has a **17-tick / 0.708 s** release-to-release floor because the next windup starts only after cooldown reaches zero (`src/ctf/sim_types.nim:741`; `src/ctf/sim.nim:3386-3397`; `src/ctf/sim.nim:4174-4183`). On a continuously fresh, aligned target, native actuation holds its A latch through windup/cooldown, spends the first newly-ready body tick lowering A, raises it on the next, and therefore releases every **19 ticks / 0.792 s** (`src/shell/body.nim:1186-1215`; `src/ctf/sim.nim:8279-8320`; `src/ctf/sim_types.nim:741`). A shield multiplies the release cooldown by **3**, making it **36 ticks** while the layer remains (`src/ctf/sim_types.nim:1181-1185`; `src/ctf/sim.nim:3843-3852`). |
| Damage | A normal landed gun hit deals exactly **1 HP** (`src/ctf/sim.nim:3962-3971`). With the manifest's **4 base HP**, an unshielded untouched seat needs four landed gun hits (`manifest:1`). There are no live perks in the manifest, so the luck branch cannot raise damage (`manifest:1`; `src/ctf/sim.nim:3962-3968`). |
| Spread | Each released shot adds Gaussian angular noise. For the live range, `sigma = asin((6 + 8) / 1300) / 1.2815516`, approximately **0.008403 rad / 0.4815 degrees** (`src/ctf/sim_types.nim:719`; `src/ctf/sim_types.nim:763-780`; `src/ctf/sim.nim:3703-3727`). This is calibrated so a centered, fully exposed body is hit **80%** of the time at **1300 px**, about **99%** at **650 px**, and approximately certain inside about **433 px** (`src/ctf/sim_types.nim:763-776`). The ray samples the target silhouette every **3 px**, admits an **8 px** bullet corridor, stops at walls, and hits the first exposed body on the ray; partial cover reduces the exposed samples (`src/ctf/sim_types.nim:777-782`; `src/ctf/sim.nim:3733-3798`). |
| Aim rate | Aim has **256 brads** per turn and changes by **5 brads/tick**, or **7.03125 degrees/tick**; a full rotation takes **51.2 ticks** (`manifest:1`; `src/ctf/sim_types.nim:827-829`; `src/ctf/sim.nim:5342-5349`). Locomotion does not turn aim (`src/ctf/sim.nim:5342-5349`). |
| Moving accuracy | There is no velocity or movement term in `aimJitterSigma`; moving does not directly widen spread (`src/ctf/sim.nim:3703-3714`). Geometry still changes: direction is locked on trigger, while the muzzle and every target are sampled at release after movement, so either seat can create a miss by changing the ray geometry or reaching cover during the **5-tick** windup (`src/ctf/sim.nim:3807-3829`; `src/ctf/sim.nim:8271-8275`). |

## Native firing and `combat_policy`

For a play-controlled seat, **yes**: when there is no guest play output, the engine recomputes a fallback order every tick; its zero-valued combat policy is the documented baseline “engage every fog-visible non-team track” (`src/shell/default_play.nim:1-2`; `src/shell/default_play.nim:55-64`; `src/shell/default_play.nim:107-113`; `src/shell/types.nim:72-79`). The same native combat layer also runs under an emitted movement/hold intent unless that intent's combat policy vetoes it (`src/shell/types.nim:81-96`; `src/shell/body.nim:1334-1358`). This is a play-shell behavior; a raw-input controller still has to provide attack buttons.

Target selection is:

1. Build candidates from enemy tracks confirmed on the current tick. “Shootable” means within the live weapon range, stone-wall ray clear, and no policy-protected fresh track in the bullet corridor (`src/shell/body.nim:803-831`; `src/shell/body.nim:858-869`).
2. Remove `no_shoot` and `protect` endpoints, then—if `hold_fire` is set—remove candidates that are not identified recent aggressors (`src/shell/body.nim:1006-1049`).
3. Compare the requested `prefer` tags lexicographically in their listed order; the first differing tag wins. Only then compare the scalar native score (`src/shell/body.nim:736-761`; `src/shell/body.nim:958-982`).
4. The scalar is `0.50*wound + 0.30*range - 0.18*aimCost - 0.10*shield + 1.0*holdsSpray`, plus **+0.35** when shootable or **-0.35** otherwise, plus **+0.65** if the target threatens a protected ward. The claim term has coefficient **0.12** but its current value is always zero (`src/shell/body.nim:37-63`; `src/shell/body.nim:833-856`; `src/shell/body.nim:1036-1049`). The range term is zero at distances at or below **120 px** and above **350 px**, rises to one by **220 px**, stays one through **300 px**, then falls to zero (`src/shell/body.nim:37-43`; `src/shell/body.nim:389-403`). Thus most of the live **1300 px** firing envelope receives no positive range-band score (`manifest:1`).
5. Target stickiness keeps the current target unless it becomes unshootable while the best is shootable, or it has been held for at least **8 ticks** and the best scalar score is at least **0.10** higher (`src/shell/body.nim:42-43`; `src/shell/body.nim:1055-1070`). The sorted “best” already reflects the preference tuple, but a tag advantage alone does not satisfy this later scalar-margin switch test (`src/shell/body.nim:958-963`; `src/shell/body.nim:1064-1069`).

The tags mean exactly:

| Tag | Value |
|---|---|
| `weakened` | `1 - min(1, knownHp / targetMaxHp)`, else zero when HP is unknown (`src/shell/body.nim:703-715`). In this live shell the max estimate is **7**, because self HP fraction uses `(4 base + 3 shield-layer capacity)` as its denominator (`manifest:1`; `src/ctf/sim_types.nim:1181-1183`; `src/ctf/server.nim:3661-3669`; `src/shell/body.nim:795-801`). Consequently a full unshielded target reported at **4 HP** scores `3/7`, approximately **0.429**, while a full shielded target at **7 total HP** scores zero (`src/ctf/server.nim:3785-3789`; `src/shell/body.nim:703-715`). |
| `isolated` | Distance to the nearest retained same-team track, divided by live weapon range and capped at one; no same-team track gives one. This scan does not require the ally track to be fresh (`src/shell/body.nim:716-727`). Since every live team has one seat, every enemy is normally tied at **1.0** on this tag (`manifest:1`). |
| `revenge` | One only when that target's seat appears as the identified attacker in self's aggressor history at age strictly below **120 ticks**; anonymous direction-only hits do not count (`src/shell/body.nim:23-26`; `src/shell/body.nim:728-732`). This is target preference, not the scoring deed named revenge. |
| `bounty` | One only while the track is current and its visible veteran marker is true (`src/shell/body.nim:733-734`). The marker means engine level at least **3** (`src/ctf/glory.nim:1305`; `src/ctf/server.nim:3647-3648`), and the play-view `bounty` field is omitted/false as soon as that track is stale (`src/shell/view.nim:1030-1037`). |

`no_shoot` is an absolute team/seat veto: the endpoint is never selected, a protected fresh seat blocks a gun corridor, and a predicted protected splash victim cancels a grenade commit (`src/shell/types.nim:65-79`; `src/shell/body.nim:776-812`; `src/shell/body.nim:1083-1102`). `hold_fire` prevents initiation but permits return fire only when the target has an identified aggressor row inside the **120-tick** window; anonymous fire cannot unlock it (`src/shell/body.nim:951-956`; `src/shell/body.nim:1024-1035`; `src/shell/body.nim:1072-1081`).

Once selected, the native layer turns toward the target and fires only while current, ready, shootable, aligned, wall-clear, and policy-safe (`src/shell/body.nim:1186-1215`). A carried grenade gets first use: native logic begins a throw only at target distance at least **90 px**, continually revalidates policy/splash, charges for the required range, and releases when aimed or forcibly after its charge overrun (`src/shell/body.nim:52-56`; `src/shell/body.nim:1217-1259`; `src/shell/body.nim:1261-1277`). Native target acquisition aims at an unshootable target but does not itself pursue it; locomotion remains the standing intent (`src/shell/body.nim:1301-1328`; `src/shell/body.nim:1353-1361`).

## Scoring geometry

The reference distances were fitted at a **1050 px** gun and are rescaled by integer floor, `referencePx * liveGunRange div 1050` (`src/ctf/glory.nim:1424-1467`; `src/ctf/glory.nim:1541-1548`; `src/ctf/glory.nim:2921-2936`). For the live **1300 px** gun:

| Gate | Live threshold | Test |
|---|---:|---|
| Point-blank | **136 px** (`110 * 1300 div 1050`) | Inclusive, kill range `<= 136` (`src/ctf/glory.nim:1425`; `src/ctf/glory.nim:2921-2936`; `src/ctf/glory.nim:2954-2956`; `manifest:1`). |
| Longshot | **866 px** (`700 * 1300 div 1050`) | Inclusive, kill range `>= 866` (`src/ctf/glory.nim:1465`; `src/ctf/glory.nim:2921-2936`; `src/ctf/glory.nim:2953-2955`; `manifest:1`). |
| Denial | **742 px** (`600 * 1300 div 1050`) from the victim's home pedestal | Inclusive, but only when the victim carries a flag/heart (`src/ctf/glory.nim:1465-1467`; `src/ctf/glory.nim:2921-2936`; `src/ctf/glory.nim:2949-2951`; `src/ctf/sim.nim:2929-2935`; `manifest:1`). This map is flagless, so denial is unreachable in the live regime (`manifest:1`; `src/ctf/sim.nim:5191-5207`). |

Kill range is the floored Euclidean shooter-victim distance at death (`src/ctf/sim.nim:2881-2886`; `src/ctf/sim.nim:2933-2935`). One kill normally gets the first matching deed in this precedence: friendly-fire penalty; denial/carrier; ace; splash multi; longshot; point-blank; revenge; rundown; escort; spray; grenade; plain tag (`src/ctf/glory.nim:2938-2961`).

**Grenade splash.** A grenade flies over walls and explodes at its landing point; walls do not shield the blast. It damages every living, non-downed body whose box touches the **52 px** circle—on-axis reach is **58 px** after the target's **6 px** half-body—including thrower and teammates (`src/ctf/sim_types.nim:1009-1028`; `src/ctf/sim.nim:4201-4246`; `src/ctf/sim.nim:4466-4472`; `src/ctf/sim.nim:4513-4535`). There are no live trenches, so damage is **2 HP** per caught body (`manifest:1`; `src/ctf/sim_types.nim:1022-1028`; `src/ctf/sim.nim:4530-4544`). Only enemy, non-self kills advance the blast's multi counter. The first valid enemy kill has `multi = false`; each subsequent valid enemy kill from that blast has `multi = true` and therefore resolves as splash-multi unless an earlier carrier/denial/ace predicate wins (`src/ctf/sim.nim:4608-4618`; `src/ctf/sim.nim:4620-4658`; `src/ctf/glory.nim:2949-2960`).

**Territory.** The deed point belongs to the team whose home pedestal has the smallest squared Euclidean distance. The comparison is strict `<`, so an exact tie remains with the first active team in iteration order (`src/ctf/sim.nim:220-242`). Under the live multiplier recut, a deed whose base class is at least **2** gains exactly **+1 integer rung** on enemy ground; class-one commons never shift, and home ground is unchanged (`src/ctf/glory.nim:2450-2463`; `src/ctf/glory.nim:2724-2742`). Flaglessness does not remove these pedestal anchors.

**Heat / embers.** Rung multipliers are **x1, x2, x4, x8** at ember thresholds **0, 1, 2, 4**; embers cap at **11** (`src/ctf/glory.nim:953-977`; `src/ctf/glory.nim:2321-2333`). The current deed reads the pre-deed ember count, then any positive-drama deed adds one ember; after **270 quiet ticks / 11.25 s**, cooling removes **2 embers**, repeating from the new decay timestamp while quiet (`src/ctf/sim.nim:249-259`; `src/ctf/sim.nim:409-410`; `src/ctf/sim.nim:476-478`; `src/ctf/glory.nim:985-992`; `src/ctf/sim_types.nim:741`). On the first hostile kill, the normal kill deed mints before the separately stacked first-blood deed. If that primary deed has positive drama, it lights the first ember and First Blood therefore sees the **x2** rung, then lights another (`src/ctf/sim.nim:2875-2952`; `src/ctf/sim.nim:3091-3094`). Closing Time and Last Light have zero drama, so a first kill reclassified to either is the exception: the primary deed neither takes heat nor adds an ember, First Blood uses **x1**, and First Blood then adds the first ember (`src/ctf/glory.nim:850-900`; `src/ctf/glory.nim:2243-2251`; `src/ctf/glory.nim:2744-2750`).

**Closing Time / Last Light.** “Closing” means the clock is inside an authored shrink segment, excluding its wait and the final hold. “Final” begins on entry to the last authored phase—including its wait and shrink—and remains true forever (`src/ctf/sim.nim:2672-2697`). A final-phase kill proposes Last Light; otherwise an actively shrinking kill proposes Closing Time. It replaces the ordinary kill deed only if its class is strictly higher (`src/ctf/sim.nim:2945-2995`). With `winAsMultiplier` live, Closing Time's base class is **3**, tying rather than replacing a class-**3** longshot; Last Light is class **4** and does replace a longshot, but ties rather than replaces a class-**4** ace tag (`manifest:1`; `src/ctf/glory.nim:2459-2463`; `src/ctf/glory.nim:2480-2486`; `src/ctf/glory.nim:2724-2742`; `src/ctf/sim.nim:2993-2995`). In this schedule, continuous closing starts at elapsed tick **259** and ends after tick **3750**; Last Light starts at elapsed tick **2476** (`manifest:1`; `src/ctf/sim.nim:2686-2697`).

**Other kill predicates.** First Blood is the first non-friendly combat kill and is the deliberate extra deed stacked on top of that kill's ordinary deed (`src/ctf/sim.nim:3091-3094`). Scoring revenge means either killing your own last killer within **240 ticks**, or—in BR—killing the enemy who killed your dead same-team partner, with the partner route mintable once per seat (`src/ctf/glory.nim:1568`; `src/ctf/sim.nim:2905-2919`; `src/ctf/sim.nim:2938-2941`). It is structurally unreachable for an ordinary one-life solo seat: a dead killer cannot shoot again and there is no same-team partner (`manifest:1`; `src/ctf/sim.nim:3218-3232`). Rundown is simply `(victim - killer) dot victimVelocity > 0` at death—positive radial velocity away from the killer, with no minimum-speed threshold (`src/ctf/sim.nim:2881-2886`; `src/ctf/sim.nim:2942`).

## Zone

Each phase applies its DPS during both its wait and its shrink. It holds the previous rectangle for `waitTicks`, linearly shrinks to its target scale for `shrinkTicks`, and the last target/DPS then holds forever (`src/ctf/sim_types.nim:4065-4078`; `src/ctf/zone_field.nim:393-441`). Cumulative live timing is:

## Movement and cover

The live fixed-point scale is **256**, and each velocity axis is independently capped at **704**, so maximum speed is **2.75 px/tick per axis**. Diagonal input is not normalized and can therefore reach `2.75 * sqrt(2) = 3.889 px/tick`, about **66 px/s axial** or **93.3 px/s diagonal** at **24 ticks/s** (`manifest:1`; `src/ctf/sim.nim:5355-5366`; `src/ctf/sim.nim:5392-5428`; `src/ctf/sim_types.nim:741`).

Stone collision is solid: the player's footprint extends **6 px** from its center in each direction and must fit wholly on walkable floor. Motion advances in one-pixel steps; a blocked step attempts a short slide, otherwise the wall absorbs that axis's motion (`src/ctf/sim_types.nim:719`; `src/ctf/sim_state.nim:589-601`; `src/ctf/sim.nim:2186-2216`; `src/ctf/sim.nim:2237-2277`).

`nearest_cover` is only a navigation-goal query over cover-atlas posts (`play_sdk/play.nim:1835-1843`). Its scorer ranks sightline, facing, and duck contrast; it grants no armor or damage multiplier (`src/shell/cover_scorer.nim:139-177`). Incoming damage has only shield absorption and then HP subtraction (`src/ctf/sim.nim:3258-3371`). Cover helps by blocking sight and bullet/spray paths—or by exposing fewer silhouette samples—not by reducing damage on a hit (`src/ctf/sim.nim:3733-3798`; `src/ctf/sim.nim:5542-5568`).

## Downed mode in solo

Every ordinary non-elimination lethal hit first calls `downPlayer`: HP becomes zero; the seat is frozen, non-colliding, unable to act or loot, but remains `alive` and retains carried items. A forced team-elimination death bypasses downing (`src/ctf/sim.nim:2603-2648`; `src/ctf/sim.nim:2824-2866`).

For an unpacted solo seat, that state is not a usable revive window. `updateDowned` immediately finalizes any ghost whose own team has no upright seat and has no upright pact ally (`src/ctf/sim.nim:7922-7967`). Weapon damage resolves before this pass, so a gun/spray/grenade down is finalized later in the same sim tick; zone/puddle hazards run after the pass, so their down survives only until the following tick's pass (`src/ctf/sim.nim:8271-8323`; `src/ctf/sim.nim:8356-8375`). Either way, with one seat and no pact there is nobody eligible to revive it.

A currently active mutual pact changes the survival unit. While an upright pact ally remains, the solo ghost gets the configured base **360-tick** bleed window. Successive downs halve it to **180**, then **90**, then the **48-tick floor** thereafter (`manifest:1`; `src/ctf/sim.nim:7893-7920`; `src/ctf/sim_types.nim:1077-1080`). An upright same-team or pact-allied seat within **40 px center-to-center** must maintain the tag for **48 consecutive ticks**; breaking range resets progress, and completion stands the ghost up at **1 HP** (`manifest:1`; `src/ctf/sim_types.nim:1072-1079`; `src/ctf/sim.nim:8030-8068`).

On painted zone ground, a ghost is immune to the ordinary DPS lump, but its bleed clock runs at **2000 permille / 2x**, turning a fresh **360-tick** window into **180 actual ticks / 7.5 s**; the live `zoneBlocksRevive` flag also resets and forbids the tag channel there (`manifest:1`; `src/ctf/sim.nim:6331-6335`; `src/ctf/sim.nim:7968-8029`; `src/ctf/sim_types.nim:741`). An enemy gun hit can splat-confirm a surviving ghost immediately; teammate or active-pact-ally gunfire cannot, while spray, grenades, and zone damage skip ghosts (`src/ctf/sim.nim:3435-3441`; `src/ctf/sim.nim:3936-3953`; `src/ctf/sim.nim:4513-4519`; `src/ctf/sim.nim:6331-6335`). Once finalized, BR sets lives to zero and never respawns the seat (`src/ctf/sim.nim:3218-3232`).

## Design implications

The qualifying gun band is **866 through 1300 px inclusive** (`src/ctf/glory.nim:2921-2955`; `manifest:1`). There is no single open-ground optimum because both sides have the same gun. At the **866 px** floor, the Gaussian formula gives about **94.6%** centered/full-exposure hit probability, maximizing longshot conversion; at **1250 px** it is about **81.7%**, and at **1300 px** exactly **80%**, reducing both outgoing and incoming hit rates (`src/ctf/sim_types.nim:763-780`; `src/ctf/sim.nim:3703-3727`). A practical safety-biased setpoint is **1200-1250 px**: it remains well above the scoring floor, retains roughly **83.5%-81.7%** full-exposure accuracy, and leaves **50-100 px** of inward margin against small measurement/movement changes. For fastest kill conversion, use roughly **866-900 px** instead; real damage avoidance should come from wall peeking, because range alone is symmetric.

Open-ground kiting can maintain a chosen distance against an equal-speed pursuer, but cannot increase it once both are at the same directional speed. At the live **6-tick** play cadence, a seat can move as much as about **23.3 px diagonally** between decisions (`manifest:1`; `src/ctf/sim.nim:5392-5428`). Native gun actuation clears movement on the trigger tick, then freezes navigation while its **5-tick** hold counter is positive; this can cost **6 movement ticks**, or about **23.3 px** of diagonal separation per shot, unless `suppressFireFreeze` is set (`manifest:1`; `src/shell/body.nim:1186-1212`; `src/shell/body.nim:1297-1308`; `src/shell/body.nim:1348-1351`). Setting that flag makes continuous kiting feasible, but the muzzle moves while the trigger-locked ray does not, so lateral motion can reduce the kiter's own hit rate (`src/ctf/sim.nim:3807-3829`; `src/ctf/sim.nim:8271-8275`). Walls, route topology, and zone pressure—not raw top speed—are therefore the hard limits on maintaining the setpoint.
